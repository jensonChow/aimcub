# apps/ios — Aimcub (native SwiftUI)

Native iOS app for Aimcub. SwiftUI, min iOS 17. Created 2026-06-29.

- **Bundle ID**: `com.jensonchow.aimcub` (registered in App Store Connect — App ID `6785268817`, team `K9XA27TP7F`).
- **Project generation**: the `.xcodeproj` is generated by [XcodeGen](https://github.com/yonsm/XcodeGen) from `project.yml`. Source of truth = `project.yml` + the Swift sources under `Aimcub/`. After changing either, run `xcodegen generate` to regenerate `Aimcub.xcodeproj` (which is git-ignored).
- **Open**: `xcodegen generate && open Aimcub.xcodeproj`.
- **Build from CLI** (Xcode-select points at CommandLineTools on this machine, so pass `DEVELOPER_DIR` instead of `sudo xcode-select`):
  `DEVELOPER_DIR=/Volumes/APFS/Applications/Xcode-beta.app/Contents/Developer xcodebuild -project Aimcub.xcodeproj -scheme Aimcub -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' build CODE_SIGNING_ALLOWED=NO`

This is a **native Swift** app and deliberately does **not** reuse the TS `@core/*` — domain logic is reimplemented in Swift or reached via the API / MCP. (This diverges from the earlier Expo-RN plan; chosen 2026-06-29.) It stays out of the pnpm/Turbo JS workspace (`package.json` carries no scripts so Turbo skips it).
